# OpenAI 企业客户案例汇总

本页索引 OpenAI 官网公开披露的企业与机构应用材料。**所有信息均来自 OpenAI 官方发布的客户故事与合作公告（或对应研究页面），属于“当事方自述”等级，效率数据和采用率需打折阅读；详细控制拆解与不可外推边界见第 16 章与附录 D。**

> **证据边界：** 本页只汇总已核验来源中明确记载的信息。客户名称、使用场景和引用的效果数据均为当事方自述，不构成对其他组织的效果承诺。具体技术实现、数据安全安排和实际运行效果需以客户方独立验证为准。

## 使用这些案例时的注意事项

1. **当事方自述等级**：本页所有案例均来自 OpenAI 官方发布，客户可能经过选择（只公开成功案例），存在幸存者偏差。
2. **效率数据需验证**：案例中引用的“节省 X% 时间”“提升 Y% 效率”等数字为当事方自述，未经过独立验证，不能作为你的目标。
3. **技术实现可能不同**：公开案例描述的是业务场景和效果，具体的模型版本、提示词设计、系统架构和安全措施可能未披露。
4. **数据安全安排不明**：企业客户使用 OpenAI 服务时的数据处理方式（是否用于训练、保留期限、加密等）需参考具体的企业协议和数据处理条款。
5. **监管环境差异**：不同行业、地区的监管要求不同，案例中的做法不能直接复制到受监管行业。

## 如何补充新案例

1. 在 [OpenAI 客户故事页面](https://openai.com/customer-stories) 找到目标案例
2. 按照[案例写作模板](./template)创建独立案例页面
3. 在本页对应行业表格中添加索引行
4. 确保所有事实都有官方来源链接，标注“当事方称”
5. 明确不可外推事项

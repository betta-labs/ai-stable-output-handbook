# 企业 AI 落地案例库

本页收录可追溯的企业 AI 落地公开案例，用于说明控制问题为何真实存在、不同组织如何选择起点和边界。**所有案例只支持其来源所记载的特定事实，不构成对你所在组织的效果承诺、采购建议或通用基准。**

> 阅读案例前，请先了解[案例与证据的分类边界](./guide)。公开案例、教学情景和受控运行证据承担不同的证明责任，不可混用。

## 如何使用本案例库

1. **按行业浏览**：找到与你业务环境相近的组织，看它们选择了什么场景、回避了什么场景。
2. **按场景浏览**：如果你已经有候选场景，看其他组织在同类场景上的控制设计和失败教训。
3. **按厂商浏览**：了解 OpenAI、Anthropic 等厂商公开披露的客户案例及其适用范围。
4. **提取控制启示**：每个案例末尾标注"应学习的控制链"和"不可外推事项"，请借鉴控制逻辑而非复制数字。

## 如何新增一个案例

如果你希望补充案例，请按照[案例写作模板](./template)准备以下信息：

1. **可定位来源**：官方公告、监管文件、权威媒体报道的 URL 和发布日期
2. **可确认的有限事实**：只写来源明确记载的内容，不推测、不扩展
3. **控制启示**：这个案例对任务定义、风险、评测、发布或回退有什么启发
4. **不可外推事项**：明确说明什么不能从这个案例推导出来
5. **来源等级**：当事方自述 / 监管裁决 / 独立调查报道 / 多方交叉验证

提交前请自查：是否区分了"当事方称"与"已查证"？是否标注了时间和适用范围？是否避免了把单一案例当成通用结论？

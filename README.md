# 企业AI稳定产出手册 (Enterprise AI Stable Output Handbook)

> 从最小闭环到企业运行系统：面向业务、交付、治理与培训的可复现AI工作方法。

**中文名**：《企业AI稳定产出手册》
**仓库**：betta-labs/ai-stable-output-handbook
**当前版本**：v1.2.0（Skill能力单元与Agent受控编排版）
**状态**：核心方法论、自诊断工具、员工工作方法、Skill能力资产、Agent治理及安全治理章节已就位，持续迭代中。

---

## 本手册解决什么问题

企业里最常见的AI使用现状是：
- **个人偶尔提效，组织整体没有明显变快**
- **Demo惊艳，真实业务中效果不稳定甚至“越用越蠢”**
- **员工对官方工具信任不足，大量使用个人账号或直接放弃**
- **缺少可复现的工作流、验证机制和长期治理**

本手册系统回答：**如何让AI在企业场景中稳定产出可靠结果。**
